#  Desafio Cadastro de Pets

Sistema desenvolvido em Java com foco em cadastro e gerenciamento de pets, aplicando conceitos de Programação Orientada a Objetos, validações e organização de código.

---

##  Sobre o Projeto

O projeto **DesafioCadastroPets** foi criado com o objetivo de praticar conceitos fundamentais de desenvolvimento backend utilizando Java.

A aplicação permite realizar o cadastro de pets e manipular informações relacionadas aos animais, simulando um pequeno sistema de gerenciamento.

Durante o desenvolvimento foram aplicados conceitos como:

* Programação Orientada a Objetos (POO)
* Encapsulamento
* Validações de dados
* Tratamento de exceções
* Organização em camadas
* Manipulação de coleções
* Entrada e saída de dados

---
